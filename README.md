A journey into the world of STM32 microcontrollers.
* EXPLORATION: Contains exploration of fundamental STM32 functionalities and peripherals with and without STM32's HAL
* MHAL: A personal Hardware Abstraction Layer （Mbua Hardware Abstraction Layer - MHAL)
* ETONDE: A personal communication frame protocol (ETONDE) defined for both sending, parsing and receiving data between devices.
